# Outside-worker quickstart

Use [Team onboarding](TEAM-ONBOARDING.md), the canonical setup guide for a single
machine or a fleet, inside or outside a tailnet.

It covers runtime and interactive-skill installation, published version pins,
provider authentication, governance choices, installation checks and a first
preview with manual closeout. Start there instead of following the former
version-specific recipe on this page.

The runner needs a roadmap in your project; it does not ingest your repository
and invent one. Installing it does not authorize pushing, merging or publishing.
Broader guided setup and portability work is tracked in
[agent-harness#927](https://github.com/Consiliency/agent-harness/issues/927).
